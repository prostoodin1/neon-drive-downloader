# Neon Drive 5.5.0 Beta 7

- Тёмная Google Drive-тема с синими, зелёными, жёлтыми и красными кнопками.
- Монитор Rclone теперь открывается только пользователем, включая обновление с Beta 6.
- Статистика по фактическим байтам каждую секунду: большие файлы не ждут первого целого процента. Во время подготовки видны состояние, время и сообщения ожидания.
- Проверка готовности папок перенесена из интерфейса в фон. Не докачанные и изменяемые исходники по-прежнему ожидают готовности.
- Google Drive использует отдельный чанк 64 МиБ, не унаследованный от локальных чанков до 2 ГиБ. Добавлен лимит памяти буферов Rclone 512 МиБ (это не лимит всей памяти процесса).
- В настройках появился необязательный дисковый буфер отдельных файлов при загрузке. После успешной передачи файл переносится в назначение, буфер удаляется; при ошибке финального переноса сохраняется для восстановления. Папки и выгрузка работают напрямую.
- Автоопределение направления для распознанных сетевых/облачных путей и пояснение маршрута. Неоднозначные пути остаются под ручным управлением.
- Нативная macOS ARM64-сборка в дополнение к Intel. Отдельный macOS Installer с историей версий, изменениями, установкой и удалением приложения в Корзину.
- README с таблицей загрузок по системам и архитектурам.

## Пакеты

| Система | Приложение | Менеджер версий |
| --- | --- | --- |
| Windows x64 | NeonDrive-Setup.exe | NeonDriveInstaller.exe |
| Mac Apple Silicon | NeonDrive-macOS-arm64.dmg | NeonDriveInstaller-macOS-arm64.dmg |
| Mac Intel | NeonDrive-macOS-x64.dmg | NeonDriveInstaller-macOS-x64.dmg |

macOS **12+**. Сборки без Developer ID и нотарификации Apple: при предупреждении об
издателе используйте [инструкцию Apple](https://support.apple.com/en-euro/102445),
если доверяете приложению. Защита системы автоматически не отключается.
Intel-only старые версии на Apple Silicon могут требовать Rosetta.

Проверки включают локальную передачу встроенным Rclone с SHA-256, поведение буфера,
регрессионные тесты и запуск пакетов. Отправка конкретного файла пользователя 25 ГБ
на Google Drive не воспроизведена: исправлены найденные причины задержек и
неинформативного прогресса, но ограничения аккаунта, сети или исходника требуют
лога с проблемного компьютера.
