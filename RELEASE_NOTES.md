# Neon Drive 6.0.4 Alpha

This Alpha release turns Neon Drive 6 into a more complete, international and publication-ready application.

## Highlights

- Added **Русский, English and Español** with immediate switching in Settings.
- Added a complete **About Neon Drive** section with version, Alpha channel, platform support and project links.
- Introduced a modern application icon across the application, Windows installer and macOS bundles.
- Rebuilt the official screenshots with fictional demo paths and identities only.
- Refreshed the compact Google Drive-inspired interface and public documentation.
- Preserved the readable high-contrast multi-folder picker from Beta 3.

## Core transfer features

- Direct Google Drive OAuth2 transfers with bundled Rclone.
- Local, external, network and mounted cloud-drive paths.
- Multiple files and whole folders, sequential or parallel queues.
- Pause/resume, full stop, source-stability checks and destination verification.
- Persistent settings and transfer counters across application updates.
- Windows 10/11 and macOS 12+ packages, plus a standalone Version Manager.

> Alpha software should be tested with non-critical data first. Keep the source until Neon reports that every transfer is complete and verified.
