# Neon Drive 5.5.0 Beta 9

## Исправления и новые возможности

- Конечная папка Google Drive теперь сначала выбирается в обычном Проводнике/Finder.
  Путь остаётся видимым, а Neon преобразует его для Rclone только при запуске.
  Отдельное облачное окно и обход всех папок больше не используются.
- Для общих дисков Windows Neon читает точные ID выбранного диска и папки из
  локального кэша Google Drive for desktop только для чтения. Поиск вложенных
  папок по имени больше не нужен; при несовпадении OAuth-аккаунта предлагается
  переподключить правильный аккаунт, сохраняя путь и автоматически продолжая запуск.
- Общий счётчик переданных данных хранится в отдельном файле данных Neon,
  автоматически переносит старое значение и больше не сбрасывается при обновлении
  приложения или смене пространства настроек версии.
- «Мой диск» работает вообще без предварительного запроса списка папок. Для общего
  диска один раз определяется только ID диска; вложенные папки не перебираются.
- Автоматически распознаются физические диски Windows (`C:`, `D:` и другие),
  сетевые пути, виртуальные папки Google Drive и прямые адреса Neon/Rclone.
  Подписи «Откуда» и «Куда» меняются прямо при вводе пути, а режим загрузки или
  выгрузки выбирается автоматически там, где направление однозначно.
- Выбор «Моего диска» и общих дисков Google Drive через OAuth2. Вложенная папка
  подтверждается по ID, а нажатие Google Drive больше не стирает назначение.
- Сопоставление пути из Проводника, включая `H:/Unidades compartidas/Clients Materials/Test carpet`.
  Недоступные или неоднозначные папки требуют ручного выбора, без подмены корнем.
  Отмена сохраняет исходный путь и не запускает другой маршрут передачи.
- Предложение «Через Neon» / «Обычное копирование» при выборе Google Drive.
  Режим сохраняется в настройках. Испанские и французские пути также распознаются.
- Кнопка «Остановить» рядом со стартом на загрузке и выгрузке; отменяется и очередь.
- «Выбрать файл» заменяет выбранные источники; «Добавить файлы» дополняет список.
- «Экстрим» с чанком Google Drive 1 ГиБ; ручной выбор 8–1024 МиБ.
  Для чанка 1 ГиБ выгружается один файл одновременно.
- Установщик не требует GitHub Desktop, CLI, Git или входа в аккаунт:
  публичный API, резервный каталог, сохранённый список и установка из скачанного файла.
  Для скачивания новых пакетов нужен интернет. Повреждённая загрузка не заменяет
  последний сохранённый установщик; новые пакеты проверяются по доступному SHA-256.
- Кликабельные ссылки на все пакеты в README, релизе и истории изменений Installer.
- HTTPS-сертификаты включены в установщик; сетевой smoke-тест готового пакета
  выполняется без GitHub CLI, токена и внешнего Python.
- На Windows определение маршрута больше не перебирает все подключённые диски,
  чтобы недоступный посторонний сетевой диск не задерживал выбор локального файла.
- Исправлена изоляция профиля тестов и предпросмотра от обычных настроек Neon.
- Исправлен запуск отложенных анимаций при добавлении файлов на macOS (Qt 6.5).

**Экстрим:** буфер одного чанка требует примерно 1 ГиБ RAM сверх остальных расходов.
Ускорение зависит от сети, дисков и ограничений Google; при нехватке памяти
выбирайте меньший чанк. Обычная копия в виртуальную папку Google Drive по-прежнему
синхронизируется клиентом Google — для его обхода выбирайте «Через Neon».

**Общие диски:** нужен Google-аккаунт с доступом. Отсутствующий диск теперь
показывает предупреждение, не отправляя файлы в другое место.

macOS **12+**, отдельные ARM64 и Intel DMG приложения и менеджера версий.
Пакеты без Developer ID и нотарификации Apple: при предупреждении об издателе
используйте [инструкцию Apple](https://support.apple.com/en-euro/102445),
если доверяете приложению. Защита системы автоматически не отключается.

Проверки: 141 регрессионный тест, реальное чтение «Моего диска» через OAuth без изменения
облачных файлов, локальные передачи встроенным Rclone, контроль хешей, отмена и
проверки собранных пакетов. Конкретный общий диск Clients Materials недоступен
подключённому тестовому аккаунту; выгрузка 25 ГБ на него не проверялась.
