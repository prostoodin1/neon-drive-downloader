# Neon Drive

Текущая версия: **5.5.0-beta.5**

Desktop-приложение для надёжного фонового копирования выбранных файлов и папок
с подключённого Google Drive на компьютер и с компьютера обратно на Google Drive
через `Robocopy`, `Rclone` или безопасный совместный режим.

Beta 5 поставляется универсальным установщиком приложения и отдельным менеджером
версий. Официальный Rclone уже включён в установку и проверяется по SHA-256 во
время сборки.

## Возможности

- выбор нескольких файлов через стандартное окно Windows;
- выбор папки или корня диска;
- устанавливаемое BETA-дополнение «Выгрузка» для отправки локальных файлов на подключённый Google Drive;
- прямое подключение Google Drive по OAuth2: браузер показывает согласие Google, после
  подтверждения Neon выгружает через встроенный Rclone без Google Drive для компьютера;
- выбор движка Robocopy, Rclone или совместного режима без одновременной записи в один файл;
- простые общие профили «Медленно», «Оптимально» и «Максимально» для загрузки и выгрузки;
- готовые профили Rclone вплоть до 32 потоков, а также ручная настройка чанков,
  передач, проверок, буферов записи и повторов внутри одного процесса;
- ожидание полной готовности исходника: незавершённые и ещё изменяемые файлы не копируются;
- фоновая диагностика системы с автоматическим восстановлением служебных папок и Rclone;
- необязательная полная диагностика и автоматическое исправление при каждом запуске;
- простой интерфейс по умолчанию и включаемая вкладка Advanced mode для технических параметров;
- тёмный dashboard по умолчанию с постоянной боковой навигацией и плавно сворачиваемой панелью;
- приглушённая светлая тема Google Drive с синими, зелёными, жёлтыми и красными контекстными кнопками;
- постоянный счётчик успешно переданных данных за период, отдельно для скачивания и выгрузки;
- ручной или автоматический ежемесячный сброс статистики;
- отдельная вкладка «Шаблоны» с карточками «Медленно», «Оптимально» и «Максимально»;
- малое, стандартное и большое окно, а также запоминание размера после ручного изменения;
- отдельные статус, прогресс, скорость, ETA и кнопка запуска внутри страниц загрузки и выгрузки;
- включаемая вкладка «Файлы» с общей очередью, путями откуда/куда, статусами,
  прогрессом и скоростями чтения и записи;
- встроенный официальный Rclone и кнопка безопасной переустановки без настройки PATH;
- реальный Google Drive upload chunk до 2048 МиБ (2 ГиБ) вручную; экстремальный
  профиль использует 512 МиБ, чтобы не расходовать чрезмерно оперативную память;
- автозапуск при входе в Windows и выбор, закрывать ли Neon после фоновой передачи;
- компактная кнопка смены загрузки/выгрузки прямо над стрелкой на Главной;
- кнопка удаления установленной версии и точное определение текущей Beta в менеджере версий;
- отдельная папка назначения;
- встроенный live-терминал в Advanced mode;
- постоянные UTF-8 логи в `%LOCALAPPDATA%\NeonDriveDownloader\logs`;
- диагностика исходников, свободного места, команды и кода Robocopy;
- пауза и продолжение процесса;
- немедленная остановка и остановка после текущего файла;
- возобновляемое копирование Robocopy (`/Z`);
- общий прогресс и приблизительное время до конца очереди;
- текущая скорость в МБ/с со сглаживанием за 15 секунд;
- ETA по оставшимся байтам всей очереди, включая файлы разного размера;
- последовательный, ограниченный и параллельный режимы с безопасным пределом 10 файлов;
- профили Robocopy: надёжный, ускоренный `/Z + /MT`, максимальный `/MT` и Turbo;
- три вида файлов на экранах загрузки и выгрузки: список, ярлыки и терминальные пути;
- кликабельные источники и ссылки на папку назначения для каждого файла;
- корректный общий прогресс по фактически переданным байтам без откатов при retry;
- тёмная тема по умолчанию, а также светлая, Google Drive и OLED-темы;
- режим малого экрана, компактный, комфортный и минималистичный режимы дизайна;
- отдельный Neon Drive Installer: новые и предыдущие версии, дата и полный список изменений;
- сохранение последней скачанной версии обновления без накопления старых установщиков;
- фоновая работа в системном трее и уведомления Windows;
- автоматический старт после выбора файлов и умная прокрутка терминала;
- настройка хранения логов и быстрый переход в папку журналов;
- плавные переходы и анимированный прогресс без консольного окна;
- мягкий горизонтальный сдвиг страниц при выборе пункта бокового меню;
- автоматическое восстановление всех настроек, активной вкладки, положения,
  размера и развёрнутого состояния окна после перезапуска.
- один экземпляр Neon Drive: повторный запуск открывает уже работающее окно;
- скрытый локальный `NeonDriveCLI.exe` с JSON-ответами для AI-агентов;
- полное завершение фонового Neon Drive и Rclone после окончания очереди,
  если пользователь закрыл окно с включённым продолжением передачи.

## Запуск из исходников

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main.py
```

## Сборка приложения

```powershell
.\build.ps1
```

Результаты сборки: `dist\NeonDrive-Setup.exe` — универсальный установщик самого
Neon Drive со встроенными Rclone и скрытым `NeonDriveCLI.exe`; а также
`dist\NeonDriveInstaller.exe` — отдельный менеджер версий. ZIP и portable-сборки
больше не создаются.

## Как использовать

1. Нажмите «Файлы…» и откройте подключённый диск Google Drive.
2. При необходимости добавьте целую папку кнопкой «Папка / диск…».
3. Выберите локальную папку назначения.
4. Нажмите «Начать загрузку» в нижней части страницы «Главная».
5. При проблеме нажмите «Открыть логи» и отправьте последний файл `session-*.log`.

Для выгрузки откройте вкладку «Обновления», установите BETA-дополнение «Выгрузка»,
затем откройте появившуюся вкладку «Выгрузка», выберите локальные файлы или папку,
затем через «Обзор» укажите папку подключённого Google Drive и нажмите
«Начать выгрузку».

## Вкладки

- **Главная** — загрузка: источники, назначение, live-терминал и карточки файлов с
  индивидуальным прогрессом, скоростью, временем и ETA.
- **Выгрузка** — BETA-вкладка, которая появляется после установки дополнения;
  локальные источники и папка Google Drive выбираются через стандартный Проводник Windows.
- **Шаблоны** — быстрый выбор общей скорости и нагрузки для загрузки и выгрузки.
- **⚙ внизу окна** — настройки beta.12, темы, плотность, диагностика и Advanced mode;
  отдельной вкладки «Настройки» в навигации больше нет.
- **Advanced mode** — движок, очередь, производительность, параметры Rclone, файлы и журналы;
  вкладку можно полностью скрыть в настройках.
- **Обновления** — автоматическая проверка, ручной выбор версий и управление BETA-дополнением.

Кнопка «После файла» запоминает текущий активный файл. Новые задачи больше не
запускаются; когда выбранный файл завершится, остальные параллельные процессы
останавливаются, оставляя частичные файлы для последующего продолжения.

В ограниченном режиме можно выбрать от 2 до 10 одновременных процессов Robocopy.
Режим «все доступные» автоматически заполняет свободные слоты, но никогда не
запускает больше 10 процессов. Это может увеличить суммарную скорость, но также
сильнее нагружает интернет-канал, диск и клиент Google Drive. Для начала
рекомендуется 2–3 одновременные загрузки.

### Профили производительности

- **Надёжный** — `/Z /J`: максимальная устойчивость и докачка текущего файла.
- **Ускоренный** — `/Z /J /MT:n`: сохраняет докачку и параллельно копирует
  несколько файлов внутри выбранной папки. Используется по умолчанию.
- **Максимальная скорость** — `/J /MT:n` без `/Z`, с более короткими повторами.
  Может быть быстрее, но после обрыва текущий незавершённый файл способен начаться заново.
- **Турбо** — один большой файл делится на независимые сегменты и читается через
  2–16 одновременных файловых потоков. Завершённые сегменты сохраняются в
  `.neon-part`, поэтому после остановки их не нужно скачивать повторно. Для папок
  этот профиль автоматически использует быстрый Robocopy без `/Z`.

`/MT` ускоряет папки с несколькими файлами. Один большой файл нельзя разбить на
несколько Robocopy-потоков, поэтому для него предназначен профиль «Турбо».
Начните с 8 турбо-потоков. Если Google Drive начинает ограничивать скорость или
диск назначения не успевает записывать данные, уменьшите значение до 4.

## Автоматические обновления

Приложение проверяет последний Release публичного репозитория
`prostoodin1/neon-drive-downloader` и скачивает установщик по прямой публичной
ссылке. Аккаунт GitHub, `gh auth login` и GitHub CLI пользователю не требуются.

При установке новая версия скачивается в `%LOCALAPPDATA%\NeonDriveDownloader\updates`.
Новые версии используют `NeonDrive-Setup.exe`: после закрытия приложения
скрытый PowerShell-процесс запускает тихое обновление установленной folder-сборки.
Старый onefile-формат автоматически получает предложение перейти на стабильную
установку без временной распаковки `_MEI`.

## Выпуск новой версии

1. Изменить `__version__` в `neon_drive/__init__.py`.
2. Закоммитить и отправить изменения.
3. Создать и отправить тег, например `v5.3.0`.
4. GitHub Actions загрузит и проверит Rclone, соберёт установщик приложения и
   отдельный менеджер версий, затем добавит оба EXE в Release.

## Скрытый CLI для AI-агентов

CLI не отображается вкладкой в приложении. После установки AI-агент может обращаться
к единственному запущенному экземпляру Neon Drive:

```powershell
NeonDriveCLI.exe status
NeonDriveCLI.exe add --source "G:\Мой диск\movie.mkv" --destination "D:\Media" --profile maximum --start
NeonDriveCLI.exe pause
NeonDriveCLI.exe resume
NeonDriveCLI.exe stop
```

Все ответы печатаются в JSON. CLI использует локальный IPC и не запускает второй
экземпляр Neon Drive или второй постоянный процесс Rclone.

При выборе пути с подключённого Google Drive чтение файла заставляет клиент
Google Drive загрузить его данные с серверов Google. Robocopy выполняет это
чтение в возобновляемом режиме и сохраняет файл в выбранной локальной папке.
Получить прямую ссылку или Drive ID из обычного пути `G:\...` Windows не умеет;
для полного обхода клиента Google Drive потребуется отдельная OAuth-авторизация
через Google Drive API и собственный браузер удалённых файлов.

Первые несколько секунд скорость и ETA показывают «Измерение…». Затем приложение
считает скорость по фактически переданным байтам за скользящее 15-секундное окно.
Так кратковременные колебания Google Drive меньше раскачивают прогноз. ETA
рассчитывается по оставшемуся объёму всей очереди, а не по количеству файлов.
